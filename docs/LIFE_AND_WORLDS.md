# 생애와 시작 환경 · 0.8.0

## 승인 범위와 구현 순서
기존 선사시대 안에서 (1) 시드 기반 환경 (2) 나이·경험별 행동 차이 (3) 거주 선택과 후속 사건을 구현했습니다. 도시 시대나 새 문명 규칙은 추가하지 않았습니다.

## 새 세계
브라우저에서 처음 시작하거나 새 세계를 만들면 새 무작위 시드를 사용합니다. 설정의 ‘같은 시드로 세계 재현’을 켜면 입력한 시드를 사용합니다. 기존 자동 저장은 먼저 복원합니다.

- 강가: 굽이치는 강, 낚시, 범람 위험.
- 숲: 숲 타일 비율이 높아 식량 밀도가 높음.
- 오아시스: 샘 주변 풀밭과 모래땅. 모래는 최대 식량 1, 28일마다 회복. 가뭄 비중이 높고 하천 범람 사건은 제외.
- 옛 야영지: 이전 집단의 미완성 거처와 돌 도구 흔적. 선사시대에 어긋나는 도시 유적은 없음.

시작 풀밭, 각 인물의 생존 자원, 도달 가능한 발견 지점과 두 대안 야영지 경로를 보장합니다. 환경과 강의 굴곡·암석·식생은 시드로 생성합니다. 시작 집단의 중앙 배치는 생존과 조작 안내를 위해 유지합니다. 계승과 불러오기에는 월드를 재생성하지 않습니다.

## 생애 단계와 실제 행동
- 12세 미만 유년기: 채집 기본량 2, 작업 부담 +2, 휴식 회복 34, 경험 1.6배. 가까운 보호자가 식량 여유가 있으면 실제 식량을 나눕니다.
- 12~17세 청소년기: 경험 1.4배, 탐험 효용 증가.
- 18~59세 성년기: 기본 작업 부담과 회복 30.
- 60세 이상 노년기: 작업 부담 +1, 휴식 회복 24, 자율 탐험 효용 감소. 나이만으로 성인 행동을 금지하지 않습니다.
- 건강 50 미만이면 추가 작업 부담 +2. 숙련 40마다 추가 부담 1을 상쇄하고 채집량이 증가합니다.
- 6세 미만은 휴식·관찰·교류를 수행하며 실험·노동은 제한합니다. 유년기 직접 이동은 주변 2칸 또는 보호자 주변으로 제한합니다. 성인이 가까이 없는 아이의 탐험 목적지는 2칸 이내입니다. 완전한 보호자 동행 경로 AI는 아직 아닙니다.
- ‘관찰하며 배우기’는 실제 가까운 인간에게 이동해 생활 경험을 얻습니다. 상대가 아는 지식만 확률적으로 배울 수 있고 전승 출처를 기록합니다.
- 12·18·60세가 되는 날 플레이어에게 중요 사건을 표시합니다. 건강과 실제 숙련은 나이와 별도로 유지합니다.
- 출생 시 개인 숙련·생애 선택은 초기화합니다. 부모의 선택·지식을 그대로 복제하지 않습니다.

생활과 생애 모드는 같은 일별 규칙을 사용합니다. 역사 모드는 기존 집계 계산을 유지하므로 개별 피로·경로를 동일하게 재현한다고 주장하지 않습니다. 역사에서도 생애 상태와 구조물은 보존하며 실제 선택은 플레이 중인 인물에게만 표시합니다.

## 삶의 첫 분기
16세 이상, 현재 삶을 45일 이상 경험하고 방문 8칸/식량 4/가뭄 중 하나를 만족하면 ‘이 땅에 남을까, 새로운 터로 갈까’가 발생합니다. 날짜만으로 자동 결론을 내리지 않으며 중요 사건에서 정지합니다.

- 남기: 현재 거주지와 집 근처 휴식 +5.
- 이주: 식량 2를 사용하고 새 터까지 실제 이동. 기존 세계와 거처는 그대로 남음.
- 동행 부탁 후 이주: 가까운 16세 이상 NPC가 기질·신뢰·식량·허기에 따라 수락 또는 거절. 거절하면 혼자 떠남을 버튼 설명에서 고지. 수락해도 NPC 자율 행동은 유지하고 생존 필요가 우선함.
- 미루기: 비용 없이 60일 후 재검토. 필수 미션이나 제한 시간 없음.

이주는 이동 취소가 가능하며 다시 목적지 근처에 도착하면 도착을 기록합니다. 도착하거나 남기로 한 지 30일 후 거처 남기기(식량 1) 또는 탐험 숙련 +25를 선택합니다. 거처는 실제 세계 구조물이며 사망·계승 후에도 남습니다. 이전 인물의 숙련이 후계자에게 자동 이전되지는 않습니다.

## 저장과 검증
저장 v5에 개인 생애 상태와 맵 환경을 기록합니다. v1~v4를 읽을 수 있으며 v4의 지형·자원·거처·날짜·플레이어·RNG는 보존합니다. 생애 상태가 없는 옛 인물에는 현재 위치를 거주지로 추가하며 과거 선택을 만들어 내지 않습니다.

단위 검사: 네 환경의 재현성과 경로, 연령별 실제 비용/회복/배움, 보호자 식량 보존, 단독 이동 제한, 선택 정지와 쿨다운, 이주 중 저장 복원, 동행 수락/거절, 사망 후 거처 보존, 기존 저장 마이그레이션, 시간 모드 일관성.

`scripts/check_life_world.py`는 Chromium의 실제 UI에서 유년기, 이주 선택, 후속 거처, 시드 재현/무작위 새 시작, 저장 복원과 모바일 패널을 검사합니다. 후속 사건은 가져오기 fixture로 시간을 앞당기며 수동 플레이 감상으로 표시하지 않습니다. 실제 휴대폰과 Safari는 미검증입니다.
