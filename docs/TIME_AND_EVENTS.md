# 시간·이벤트 재설계 — 우선 적용 규칙

## 단계별 구현

1. 기존 일일 규칙을 유지하고, 하루 진행과 외부 스냅샷 생성을 분리했습니다.
2. 생활 1일, 생애 30일, 역사 1,825일을 한 번의 시계 호출에 진행합니다. 모든 묶음은 매일 중단 조건을 검사합니다.
3. 조건 기반 이벤트, 게임 내 날짜 쿨다운, 독립적인 날짜 난수를 추가했습니다.
4. 역사 집계, 문화·출생·세대 전승, v2 저장 복원, UI와 회귀 검증을 추가했습니다.

## 시간과 플레이어 신분

| 모드 | 현실 1초 / 1배속 | 계산 |
|---|---|---|
| 생활 | 1일 | 기존 Utility AI·이동·욕구·관계·기술의 하루 처리 |
| 생애 | 30일 | 동일한 하루 처리를 최대 30번 반복; 결과는 생활 모드의 동일 일수와 같음 |
| 역사 | 5년 = 1,825일 | 개인 경로 탐색 생략; 일별 자원·건강·노화, 월별 인구·관계·전승 집계 |

달은 고정 30일, 해는 365일입니다. 기존 2배·4배속은 각 모드 기준 속도에 곱합니다. 모드 전환은 자동 일시정지하며 새 모드의 시작은 사용자가 재생합니다. 부분 현실 시간은 기존 정책대로 버립니다.

역사는 생애 결산을 확인한 후에만 열립니다. 살아 있는 플레이어는 `이 삶 마무리하기` → 확인 화면 → `마무리 확정`으로 조작을 종료할 수 있습니다. 이 선택은 캐릭터를 죽이지 않고 자율 NPC로 남깁니다. 사망에 의한 종료와 구분해 결산에 표시합니다. 같은 생존 캐릭터를 바로 다시 선택하는 것은 차단합니다. 새 인간을 선택하면 생활 모드·일시정지로 돌아옵니다. NPC를 관찰하는 클릭은 여전히 신분을 바꾸지 않습니다.

중요 사건·사망·결산에서는 남은 묶음과 누적 시계 호출을 즉시 중단합니다. 건강 15 이하 또는 80세까지 30일 이하인 상태는 위기 사건으로 알립니다. 확인 후 진행하면 자연적인 사망은 발생할 수 있지만 자동으로 계승하거나 사망 이후 날짜를 건너뛰지 않습니다.

## 역사 집계의 차이와 유지되는 상태

- 실제 인물·나이·보유 지식은 유지합니다. 모드 전환 시 별도의 세계를 재생성하지 않습니다.
- 일별: 살아 있는 인구만큼 지역 자원을 차감합니다. 충분하면 허기를 낮추고 건강을 회복하며 부족하면 굶주림·건강 고갈이 발생합니다. 이동 경로·예약 지시는 끝내고 개별 경로 탐색은 하지 않습니다.
- 월별: 살아 있는 전승자가 미보유자에게 지식을 가르칠 수 있습니다. 수용 확률은 공동체 협력 문화에 영향을 받습니다. 개별 생활·생애 모드에서도 실제 교류를 통한 지식 전달이 가능합니다.
- 월별: 인접한 인물 목록 사이에 관계가 조금씩 형성됩니다. 이는 물리적인 타일 접촉을 계산하는 생활 모드와 다른 근사입니다.
- 18~59세 성인이 둘 이상, 자원이 충분하고 인구가 30 미만일 때 출생할 수 있습니다. 월별 확률은 성인 수/180입니다. 신생아는 지식을 자동 상속하지 않으며 이후 문화적 전승으로 습득합니다.
- 건강 0 또는 80세에 사망합니다. 사망자를 기술 보유자에서 제외하고 전승자가 없어진 지식의 소실을 기록합니다.
- 문화의 협력·전승 수치는 0~100입니다. 식량 여건과 전승에 따라 변화하며, 저장과 모드 전환을 거쳐 유지됩니다.
- 자원 재생과 기술 정착 효과는 기존 게임 내 7일 경계를 사용합니다. 모든 모드에서 자원은 음수가 되지 않습니다.
- 화면용 사망 인물은 최근 30명과 플레이어 신분을 유지합니다. 누적 출생·사망 수와 현재 생애 결산은 별도로 보존합니다.

역사 모드는 상세 생활 시뮬레이션의 완전히 동일한 고속 실행이 아닙니다. 타일 위치·채집 경로를 집계 자원 접근으로 대체하므로 이후 결과가 달라질 수 있습니다. 동일한 초기 상태·모드 전환 시점·명령에서 재현되며, 같은 모드에서는 묶음 크기와 렌더링 속도가 결과를 바꾸지 않습니다. 역사로 넘어갔다 돌아올 때도 인물·자원·문화·기술의 상태를 그대로 사용합니다. 세계 시대는 아직 선사시대이며 미래 콘텐츠 자체가 추가된 것은 아닙니다.

## 이벤트와 초기 밸런스

발생 여부는 시드·절대 게임 날짜·이벤트 종류의 해시를 사용합니다. 모드·FPS·현실 시간은 확률에 들어가지 않습니다. 검사 순서는 위기 → 대화 → 기술 정착 → 문화 변화 → 일반 기록입니다. 중요 사건이 대기 중이면 추가 시간이 흐르지 않습니다.

| 사건 | 조건과 일별 확률 | 게임 내 쿨다운 | 처리 |
|---|---|---|---|
| 삶의 위기 | 플레이어 건강 ≤15 또는 80세까지 ≤30일 | 30일 | 자동 정지 |
| 대화의 기회 | 플레이 중 주변 세계에 생존 NPC 존재·현재 삶 시작 후 900일 이상, 1/600 | 900일 | 자동 정지, 확인 후 기존 교류·부탁으로 개입 가능 |
| 기술 정착 | 하나 이상의 기술이 공동체에 정착 | 500년 | 자동 정지 |
| 문화 변화 | 전승 문화 ≥30·경과 500년 이상, 1/(365×1000) | 1,000년 | 자동 정지 |
| 일반 일상 | 1/20 | 30일 | 로그만 |

쿨다운을 포함한 반복 발생의 기대 간격은 생활의 일반 일상 약 50초, 생애의 대화 기회 약 50초, 역사의 문화 변화 약 400초입니다. 첫 대화는 최소 900일, 첫 문화 변화는 최소 500년 경과 조건도 사용합니다. 쿨다운·조건·난수 때문에 실제 간격은 더 길거나 짧을 수 있으며 보장된 미션 타이머가 아닙니다. 특히 동일 게임 내 확률을 유지하면서 모든 모드의 실제 사건 간격까지 같게 만들지는 않습니다. 장기적인 플레이 재미와 30~60초/5~10분 목표는 실제 플레이테스트에서 추가 조정해야 합니다.

## 저장 호환성과 검증

스냅샷 v2는 시간 모드, 이벤트 대기·쿨다운·로그, 문화, 누적 인구 변화, 다음 인물 ID를 포함합니다. UI에서 JSON 파일 내려받기·불러오기를 제공합니다. 불러오기는 항상 일시정지이며 손상된 파일은 현재 세계를 교체하지 않습니다. IndexedDB 자동 저장은 아직 없습니다.

직전 단일 캐릭터 버전의 v1 스냅샷은 세계·난수·플레이어 상태를 보존하고 생활 모드·기본 문화·빈 이벤트 이력으로 변환합니다. 플레이어 신분/생존 필드조차 없던 더 오래된 초기 개발 스냅샷은 지원하지 않습니다. 당시 배포본에는 파일 저장 기능이 없었습니다.

자동 테스트: 모드별 1초 속도, 생활/생애 동일 일수 결과, 중요 사건 중간 중단과 쿨다운, 생애 종료 게이트, 300년 인구·자원·기술·문화 유지, 역사 묶음 크기 독립성, 난수·저장 복원 재현성, v1→v2 변환. 실제 휴대폰 성능 및 긴 실시간 플레이의 재미는 별도 검증 대상입니다.
