# STEP 3 — 인간과 자율 행동

마스터 명세 PART 4, STEP 3을 구현한 초기 조정값입니다. 최종 밸런스는 아니며 기술·노화·사망·계승은 포함하지 않습니다. 의존성 추가는 없습니다.

## 모델과 하루 처리

기질은 시드로 생성한 0~100 정수 네 가지입니다. 건강·허기·피로·외로움은 0~100, 개인 식량은 정수로 관리합니다. 초기 식량 2개, 건강 100, 허기 15, 피로 10, 외로움 20입니다. 나이는 기존 초기값만 표시/보유하며 노화는 STEP 6에서 구현합니다.

매일 순서대로:

1. 허기 +7, 피로 +3, 외로움 +3.
2. 식량이 있고 허기가 20 이상이면 1개 먹고 허기 −28.
3. 허기가 85 이상이면 건강 −5, 45 미만이면 건강 +1.
4. 자동 모드는 현재 욕구·기질·자원·교류 상대를 평가합니다. 경로를 수행 중이라도 허기가 75를 넘으면 다른 자동 행동에서 채집으로 재평가할 수 있습니다.
5. 이동 경로를 하루 한 칸 진행하고 피로 +2. 방문한 타일을 기록합니다.
6. 목적지 도착 또는 제자리 행동 수행 후 효과를 적용합니다.

인물은 고정된 배열 순서로 계산합니다. 같은 시드·명령 순서·틱 수의 결과가 같습니다. 자동 행동은 플레이어 입력 명령으로 기록하지 않고 시뮬레이션 결과로 발생합니다.

## Utility AI

네 행동을 연속 점수로 평가합니다. 허기와 부족한 식량은 채집, 피로와 낮은 건강은 휴식, 호기심·위험 감수는 탐험, 외로움·사회성은 교류 점수를 높입니다. 안정 추구는 채집·휴식을 선호하게 하지만 탐험을 금지하지 않습니다. 심한 허기에는 채집에 추가 생존 우선값을 줍니다.

실행 가능한 행동을 높은 점수부터 시도합니다. 채집 자원이 없거나 교류 상대에게 도달할 수 없으면 다음 행동을 시도합니다. 탐험은 같은 반경 안에서 방문하지 않은 땅을 우선하되 시드 난수로 목적지 순서를 바꿉니다. 점수와 플레이어 개입 여부는 인물 패널에서 확인합니다.

## 행동 효과

- 채집: 반경 8 안의 가까운 자원까지 경로 탐색. 도착 시 최대 3개를 개인 식량으로 획득하고 피로 +6. 허기가 20 이상이면 얻은 식량으로 즉시 식사할 수 있습니다.
- 휴식: 피로 −30, 허기 70 미만일 때 건강 +4.
- 탐험: 반경 5의 도달 가능한 새로운 땅 우선. 방문 타일 기록은 생존자별로 유지합니다.
- 교류: 반경 8의 가까운 도달 가능한 상대를 향해 이동. 상대가 12칸 밖으로 멀어지면 종료. 접촉 시 양쪽 친밀도 +8, 신뢰 +5, 외로움 −30. 관계는 0~100으로 제한합니다.

초원 자원 용량 3, 숲 6, 강·암석 0입니다. 채집은 자원을 실제 차감하고, 7일마다 초원·숲 자원 1개가 용량 안에서 재생됩니다. 동시 채집은 인물 처리 순서에 따라 남은 자원만 획득합니다. 자원 가시화는 현재 타일 잔량 표시로 제공하며 지도 자원 아이콘은 아직 없습니다.

## 플레이어 개입

일시정지 중 이동·채집·탐험·휴식·교류를 예약할 수 있습니다. 새 지시는 기존 경로와 행동을 교체합니다. 직접 지시는 자율 선택보다 우선하며, 한 번 완료 후 자율 모드로 돌아갑니다. 식사와 건강 변화는 직접 지시 중에도 계속됩니다. 취소하면 경로를 즉시 지우고 다음 틱부터 자율 행동을 평가합니다. 도달 불가능한 지시는 기존 행동과 난수 상태를 유지한 채 거절합니다.

## 검증과 한계

자동 테스트는 허기·피로 우선순위, 연속 기질 가중치, 식사·채집의 실제 효과, 자원 고갈, 휴식, 상호 관계 형성, 탐험, 지시 취소, 12명의 자율 활동, 플레이어 개입을 포함한 365일 결정론을 검사합니다. 기존 시계·좌표·경로·이동 테스트도 유지합니다.

건강 0에서도 사망하지 않습니다(STEP 6). 기술·지식 전승은 아직 구현하지 않습니다(STEP 4). 허기·피로·관계는 초기 모델이며 가족·사회 역할·협력 작업·질병·전투는 구현하지 않았습니다. 행동 기록은 최신 100건만 보관하고 UI는 최근 6건을 보여줍니다. 장기 역사·생애 기록으로 취급하지 않습니다. 최종 애니메이션 대신 인물 옆 색 점으로 행동을 구분합니다. 실제 휴대폰 성능·GPU별 호환성은 추가 검증이 필요합니다.
