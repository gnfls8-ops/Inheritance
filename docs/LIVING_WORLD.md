# 0.7.0 — 삶의 변화와 살아 있는 골짜기

사용자 승인 범위: 채집 생활 → 정착지 형성 → 초기 재배 생활. 이후 시대와 도시 확장은 이번 범위가 아닙니다.

## 경험과 시간
첫 생애는 주변 발견, 생존, 관계, 개인 지식, 남길 장소와 전승을 경험합니다. 여정 창은 선택적 길잡이이며 강제 미션이 아닙니다. 반복되는 일상을 요약하고 싶으면 생애 모드로 이어 삽니다. 생존 중 은퇴·계승은 여전히 금지합니다.

사망 후 결산에 발견·배움·전승 외에 거처와 수확 등 생활의 흔적을 표시합니다. 역사 모드에서는 대표 인물의 조사·건축·재배·실험을 월별로 집계합니다. 생활 방식이 바뀌면 즉시 정지하여 다른 인간의 삶으로 들어갈 기회를 줍니다. 계승 선택은 사용자가 합니다.

첫 생애의 핵심 경험을 20~30분 안에 보여주는 것은 초기 설계 목표입니다. 강제로 수명을 줄이거나 그 시각에 시대를 전환하지 않습니다. 실제 20~30분 사용자 플레이의 체감 평가는 아직 하지 않았습니다.

## 활동
- 탐험: 가까운 미발견 흔적을 우선 탐색 → 도착 → 2일 조사. 열매 군락, 샘, 돌 산지, 야생 곡물을 개인별로 기록합니다. 같은 인물의 중복 발견 보상은 없습니다.
- 낚시: 12칸 이내 도달 가능한 강가로 이동 → 3일 작업 → 식량 2~4. 가뭄은 1, 풍요는 5.
- 거처: 식량 2 이상일 때 예약. 새 작업 시작에 식량 1 사용, 3회 작업으로 완성. 여러 사람이 참여하면 공사 진척을 공유합니다. 주변 2칸의 휴식 피로 회복 +10.
- 재배 실험: 개인의 식량 저장 지식, 야생 곡물 발견, 세계에 완성 거처가 필요. 지식을 얻은 인물만 밭을 돌볼 수 있습니다.
- 밭: 거처 4칸 이내 빈 풀밭에서 2일 작업, 파종 식량 1. 파종 후 30일에 수확 가능. 수확 작업 2일, 식량 기본 7 / 가뭄 3 / 풍요 10.
- 조사·낚시·건축·재배 작업 중 매일 피로 +4. 이동과 기본 생존 비용은 별도입니다.
- NPC는 자신의 욕구·기질·지식으로 활동을 고릅니다. 플레이어가 부족 단위 건축/생산을 명령하지 않습니다.

## 자연 변화
42일째부터 120게임일 간격으로 풍요/가뭄/범람을 예고합니다. 3일 후 시작해 30일간 지속합니다. 시드와 게임 내 날짜만으로 결정하며 속도나 렌더링 난수를 사용하지 않습니다.

풍요는 자원 회복/수확 증가, 가뭄은 자연 자원 회복 정지/수확 감소, 범람은 강가 자원 감소 및 시작일 강가 작물 유실입니다. 직접 체력을 깎거나 인물을 강제로 죽이지 않습니다. 간접적인 식량 부족은 기존 생존 규칙에 영향을 줍니다.

일반 예고는 기록과 지도 길잡이로 표시합니다. 내 낚시·내 강가 작물 또는 가뭄 속 심각한 식량 부족에 관련된 예고만 자동 정지합니다. 예고 확인 뒤 수확 가능한 작물을 거두거나 새 밭의 위치를 바꾸는 등 대응할 수 있습니다.

## 조건 기반 생활 단계
- 정착지 형성: 완성 거처 2곳 + 식량 저장 지식을 가진 생존자 2명.
- 초기 재배 생활: 정착 이후 실제 수확 누적 2회 + 재배 지식을 가진 생존자 2명.
- 한 번 도달한 단계는 역사 기록으로 남습니다. 이후 지식 소실이 발생하면 실제 행동은 현재 보유 지식에 따라 제한됩니다.

## 표현과 저장
별도의 조사·낚시·건축·밭 작업 동작, 공사 골조, 완성 거처, 파종/성장/수확 가능 밭을 표시합니다. 이전의 장식용 거처를 실제 건축물로 교체했습니다. 자연 상태에 따라 지면 색과 범람의 비 표현을 바꿉니다.

저장 v4. v1~v3는 인물, 날짜, 자원, 난수를 유지하면서 새 자연/장소 상태를 초기화합니다. 과거에 없었던 건축이나 발견을 소급 생성하지 않습니다. 진행 중인 새 작업과 밭의 성장 시점은 저장·복원됩니다.

## 검증
- TypeScript/Vite 빌드 및 자동 테스트 78개 통과.
- 단위/통합 테스트: 이동일과 작업일 분리, 조사 2일 및 중복 발견, 낚시 3일, 공사 진척/휴식 효과, 파종 비용/성장/수확, 개인 재배 조건, 범람의 강가 한정 피해, 모드별 자연 변화 일관성, 조건 기반 단계 전환, v3 복원, 작업 중 재현성, 관련 재해 예고 정지.
- Chromium UI: 탐험 조사/발견, 낚시 중간 저장 복원, 공사 완성, 수확 후 단계 전환 정지, 범람 작물 유실, 구버전 파일 복원, 모바일 여정 창.
- 기존 전체 플레이와 300년 이상 브라우저 진행·전승·자동 저장 복원 회귀 검증 통과.
- 실제 iOS/Android/Safari 및 공개 URL 응답은 기존 환경 제약으로 미검증. 미세한 체감 밸런스와 음향/아트 선호도는 출시 후 피드백 대상입니다.
