- 모바일 픽셀 캔버스 해상도 최적화 및 인물 팔레트의 ID 기반 고정.

## 자동 검증
- TypeScript/Vite 프로덕션 빌드 통과.
- Vitest 9개 파일, **65개 테스트 통과**.
- 저장 마이그레이션, 손상/용량 실패 처리, 109,500개 대기 기록의 무손실 저장/복원.
- 인물 권한, 사망·중요 사건 즉시 중단, 생활/생애 동일 일수 결과, 300년 역사 재현성과 전승, 쿨다운, 보간의 정지/프레임 분할.
- git diff --check 통과.

## 실제 Chromium 자동 조작
- 최초 선택 → NPC 관찰/부탁 → 기술 발견·전승 → 사망/결산 → 역사 관찰 → 계승 → 파일 저장/복원.
- 1440×900, 390×844, 360×640, 844×390에서 창 동작과 화면 넘침 확인.
- 모바일 터치 환경에서 브라우저 입력 API로 두 손가락 핀치. 지도 확대 후 이동 명령이 추가되지 않음을 확인.
- 자동 저장 새로고침 복원, 손상된 최신 저장의 백업 복구.
- 사용자 버튼으로 AudioContext 시작/정지 확인. 청취 품질 평가를 대신하지 않음.
- 실제 브라우저 시계 4배속 역사 진행: **120,451일(약 330년)**, 출생 123명 / 사망 106명 / 전승 252건. 저장 후 새로고침으로 같은 날짜 복원.
- 전체 흐름 JavaScript 오류 0건.
- 모바일 에뮬레이션/SwiftShader에서 10초 동안 559프레임(평균 약 55.8fps), 프레임 간격 p95 33.2ms. **실제 휴대폰 성능 수치가 아님**.
- 원시 측정값: [RELEASE_METRICS.json](RELEASE_METRICS.json).

재현: 빌드한 dist를 127.0.0.1:4180에서 제공한 뒤 Python Playwright/Chromium 환경에서
`python scripts/check_browser.py`, `python scripts/check_release.py`.
서버/브라우저 경로는 INHERITANCE_URL, CHROMIUM_PATH 환경변수로 변경 가능.

## 밸런스 기준과 한계
생활 1배속의 만남 안내 간격은 최소 45초이며 주변 생존 인물 조건에 따라 늦어질 수 있습니다. 사건 확률과 쿨다운은 게임 내 일수 기준으로 유지합니다. 생애·역사 모드에서 현실 초 단위로 동일한 사건 빈도를 강제하지 않습니다. 역사 문화 변화는 기존 문화 조건과 게임 일수 확률을 사용합니다. 장기간 플레이어 체감 밸런스와 아트/음향 선호도는 출시 후 피드백 대상입니다.

## 환경상 검증하지 못한 항목
- 실제 iOS/Android 기기 및 Safari: 기기 접근 없음. WebKit 다운로드도 네트워크 정책의 Domain forbidden(403)으로 실패.
- 공개 GitHub Pages URL 응답: 환경의 프록시가 gnfls8-ops.github.io 연결을 403으로 거절. 배포 브랜치 업로드/원격 커밋 확인과 공개 URL 검증을 구분합니다.
- 이후 시대별 아트와 자율 도시 성장: 사용자 선택에 따라 이번 범위에서 제외. 배경 거처는 장식입니다.
