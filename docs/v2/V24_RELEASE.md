## 2030 자동화 경로

기존 E02를 2030년 이후 조건 사건으로 조정했다. 국가 사건 사이에는 최소180일 간격을 둔다. 새로운 정책을 선택할 때마다 사람을 다시 추첨하지 않는다.

| 시점 | 계산되는 변화 | 원인 기록 |
|---|---|---|
| 정책 선택 | 기존 즉시 국가 효과·생활 규칙, 의도한 편익과 비용 | E02 / NATION |
| 1개월 뒤 | 설비 투자, 사무실·공장 장비 설치, 기술 교역 연결성의 작은 외부 효과 | E02 / GLOBAL·CITY |
| 6개월 뒤 | 사무직·생산직 일부 실직 또는 업무 변경. 재교육 접근성이 충격 확률을 완화 | E02 / HUMAN·NATION |
| 당사자 후속 | 구직/재교육 선택 → 수개월 뒤 결과 선택. 해당 시점의 채용 조건·역량으로 새 직업 시도 | E02 / HUMAN |
| 3년 뒤 | 생산성 증가와 환경 비용, 분배 정책 유무에 따른 격차 변화. 자동화 설비 가동 | E02 / NATION·CITY |
| 4년 뒤 | 재교육 투자에 따른 고용·신뢰 회복 또는 지원 부족의 충돌 | E02 / NATION |

세계 기술 최전선의 독립 계산은 유지하며 국가의 기술 교역이 연결성에 주는 작은 효과만 별도로 기록한다. 국가가 세계 기술을 직접 덮어쓰지 않는다. 인물 배정에는 정책 피해/수혜를 사용하지 않는다. 실직 대상은 같은 시드·조건에서 같은 결과를 얻는 표본 규칙이며 모든 사람의 실직을 보장하지 않는다.

기존 정책의 즉시/지연 수치 효과를 중복 실행하지 않는다. 기존 지연 효과에도 원인 ID를 기록한다. 도시 착공은 관련 정책과 사회 조건의 공동 결과로 설명하며 단일 정책이 모든 변화를 일으켰다고 표시하지 않는다. 정책 파급에 따른 고용·훈련·생활비 상태는 개인 사건의 조건과 후속 채용 가능성에 영향을 준다.

## 반복과 생활 표현

P01/P02/P03/P10은 직업·고용·전직·훈련 상태가 같은 동안 반복하지 않는다. 생활비/건강 문제는 상황이 충분히 회복된 뒤 다시 발생할 수 있다. 일상 대사는 대화 선택창을 만들지 않는다. 재교육 등 선택으로 만들어진 후속 사건은 일정 시점에 우선 처리한다.

일별 게임 결과와 시설 방문 일정은 저장에 포함된다. 보행/소품 애니메이션과 카메라는 시각적 보간이며 경제를 다시 계산하거나 RNG를 소비하지 않는다. 장기 진행은 기존 일별 계산을 사용하고 도시 기록 타임랩스를 재생한다. 1일의 여러 방문을6초로 압축한 표현이며 개별 시간대 경제 모형은 아니다.

## 한계

- 2030년 E02 자동화 촉진이 가장 상세한 다단계 파급 경로다. 나머지9개 정책은 기존 즉시/지연 효과와 도시·개인 연결 및 인과 기록을 유지하며, 모두 동일한 규모의 전용 사건 트리를 가진 것은 아니다.
- 고정 180명/시설10개의 생활권을 유지한다. 도시 면적 확대·새 국가·2050년 이후는 이번 변경에 포함하지 않는다.
- 기존 원본 쿼터뷰 픽셀 표현에 소품·설비·로봇을 추가했다. 상용 수준 고밀도 최종 아트 제작은 미완료다.
- 실제 휴대폰·Safari·사람의 플레이 감상은 별도 검증이 필요하다. 자동 조작 횟수나 검사 시간은 재미/20–35분 플레이 목표를 증명하지 않는다.
- 한 화면 주민 표본은 최대24명이며 말풍선은 그중 최대3개다. 중요 대사는 인물 기록에서 다시 볼 수 있다.
