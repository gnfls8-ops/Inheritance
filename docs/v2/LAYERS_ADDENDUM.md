# v2.2 / v2.3 — 추가 승인 명세와 통합 설계

사용자 승인: v2.0·v2.1을 유지하며 v2.3까지 완료, 테스트 환경과 GitHub Pages 빌드·배포.

## 필수 요구
- GLOBAL → NATION → CITY → HUMAN.
- 가상 기술 산업 국가 아르카디아. 국가 정책과 독립적인 세계 기술 발전.
- 아르카디아의 기존 인구에서 나이·직업·소득·기질을 함께 무작위 배정. 이전 인물은 계속 생활.
- 건물·교통·자동화·환경이 실제 상태에 따라 기존 → 공사 중 → 완공으로 변화.
- 시간 건너뛰기에서는 실제 계산된 도시 변화를 타임랩스로 관찰.
- 2D 쿼터뷰, 현실적 비율의 밀도 있는 픽셀 표현.
- 결정론, 저장 호환성, 기존/신규 검사, 브라우저 배포.

## 기존 코드 분석 및 변경 경계
이미 작성한 FutureSimulation, 180명 Utility AI, 10개 국가 사건, 12개 개인 사건, 생애 단계, IndexedDB 및 React 화면을 재사용한다. 기존 `world` 12지표는 실제 역할이 아르카디아의 사회 지표이므로 `nation.metrics`로 명확히 옮긴다. 정책 rules/선택 이력은 기존 모델을 유지한다.

신규 `global`은 기술 최전선·에너지 효율·연결성을 월별 계산한다. 정책이 직접 세계 기술을 덮어쓰지 않으며 국가의 혁신/접근성이 확산 속도에 영향을 준다. 신규 `city`는 건물별 단계/수준/진척/착공일/완공일을 보존하고 완공된 교육·교통·자동화·녹지 시설이 개인의 학습·생산·비용·스트레스에 영향을 준다. 달력 연도만으로 도시를 교체하지 않는다.

계산 순서: 일별 개인 활동 → 월 경계의 정책 지연 효과 → 세계 기술 → 국가 변화 → 도시 사업 → 가계 결산. 시드 RNG는 기존 하나만 유지. 도시 조건/공사 계산은 추가 RNG를 사용하지 않는다.

세이브 버전 23. 미게시 v20 세이브의 `world`를 국가 지표로 옮기고 과거 도시 증거는 만들어내지 않는다. 기존 180명·출생일·난수 상태·정책·생애 기록을 그대로 유지하며, 신규 계층은 초기 상태로 도입한다. 이미 지났던 세계 기술은 정책과 독립적인 월 계산으로 복원하고, 도시는 복원 시점부터 공사를 시작한다. 신규 버전의 왕복 저장은 완전히 동일해야 한다. 선사시대 v5는 별도 보존.

타임랩스는 실제 월별 도시 스냅샷의 재생이며 경제 계산을 다시 실행하지 않는다. 중요 사건에 도달하면 계산이 멈추고 마지막 프레임 이후 선택 화면을 표시한다. 재생 정지/건너뛰기 가능. 저장 데이터에는 시각 재생 큐를 넣지 않는다.
