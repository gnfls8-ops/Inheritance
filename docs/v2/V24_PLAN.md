# v2.4 인간 중심 플레이

사용자 승인된 범위: 기존 4계층과 RNG/정책/인구를 재사용하여 카메라·말풍선·생활 동선·정책 파급·연쇄 사건·도시 운영을 확장하고 Pages에 배포한다.

1. 생활 관찰 기본 확대/가장자리 추적. 도시 관찰은 전체 지도를 조망. 생활 속도 기본 하루6초(2×/4× 지원)로 실제 동선을 관찰할 여유를 둔다. 장기 진행 계산 규칙은 그대로 유지.
2. 기존 인물의 날짜별 생활 일정(집→직업/학습/구직 시설→상점/공원/교류→집), 건물 입구 및 보행 경로 재사용. 시설 활동은 보행과 구분되는 픽셀 애니메이션.
3. 데이터 기반 대사, 중복 기억, 동시3개 이내 말풍선. 중요/정책 대사는 읽을 수 있는 알림에도 보존.
4. 원인 정책 ID가 있는 인과 기록과 지연 파급 큐. 기존 즉시/지연 효과를 중복 계산하지 않고 기록을 추가한다. 자동화 정책의 투자→설비→고용 재편→생산/분배/환경 후속 결과. 재교육·복지 선택에 따라 완화/충돌.
5. 기존 개인 사건은 상태 문맥별 반복을 제한하고 선택에서 나온 후속 사건을 우선 처리. 2030년 E02 자동화 정책으로 MVP 경로 검증.
6. 경제 악화시 상점 휴업/회복, 자동화 설비·로봇은 실제 시설 상태에 연결.
7. 저장24, 형식20/23 이관. 과거에 발생하지 않았던 파급효과/대사를 만들어 넣지 않음. 과거 정책의 아직 미발생인 기존 지연효과는 그대로 유지.
8. 단위/전체 경로/브라우저/모바일/저장 검사 후 배포. 임시 원본 픽셀 표현을 유지하며 상용 최종 아트로 표시하지 않음.
