## 재사용·비활성화·신규 구현

재사용: TypeScript/React/Vite/PixiJS, 단일 SeededRandom, MotionTrack 시각 보간과 결정론적 코어 원칙. 이전 선사시대 코드 및 93개 회귀 검사는 보존했다. 이전 상태는 `backup/pre-v2-0.8.0` 태그에 남겼다.

비활성화: 새 엔트리에서 선사시대 채집·부족 기술·기존 렌더러·직접 첫 인물 선택 화면을 불러오지 않는다. 기존 파일과 저장을 삭제하지 않는다.

신규: `src/future/`의 모델·인구·국가 정책·일별 행동·월별 경제·독립 세계 기술·도시 사업·사건·관점 전환·결산·저장·도시 화면·UI. 외부 AI API나 분석/전송 서버를 사용하지 않는다.

## 인물 배정과 나이

초기 가상 인구 180명을 생성한다. 연령 집단 비중은 아동 18%, 청소년 12%, 청년 23%, 중장년 32%, 노년 15%이며 실제 국가 통계가 아니다. 현재 10세 이상 생존 인구에서 균등 추첨하므로 플레이 가능한 집단의 분포로 조건화된다. 기존 인물의 출생일·직업·소득·기질을 함께 사용한다. 첫 정책의 수혜/피해로 추첨을 조정하지 않는다.

출생일과 세계 날짜로 나이를 계산한다. 아동0–12, 청소년13–19, 청년20–34, 중장년35–59, 노년60+. 20세 미만의 노동·구직 제한은 이 가상 국가 MVP의 규칙이다. 교육·AI·창작·관계·휴식·공동체 활동은 가능하다. 미성년 생활비는 가족의 실제 자산 이전과 사회보장으로 지원한다. 나이가 호기심·AI 숙련·행복의 초기값을 결정하지 않는다. 노년의 체력 비용과 선택적 은퇴는 별도 반영한다.

2034·2042년 또는 사망 때 기록을 남기고 다른 관점으로 추첨한다. 살아 있는 이전 인물은 계속 계산된다. 사망자는 다시 배정하지 않으며 사망 시점 나이가 유지된다. 2050년의 살아 있는 인물은 중간 결산, 사망 인물은 생애 결산으로 구분한다.

## 계층별 계산과 시간

- **GLOBAL:** 기술 최전선·에너지 효율·연결성의 독립적인 월별 발전. 아르카디아 정책을 세계 전체에 직접 적용하지 않는다.
- **NATION:** AI·자동화·생산성·고용·분배·안정·자유·복지·접근성·신뢰·환경·삶의 질 12지표. 정책 즉시/지연 효과, 세계 기술 확산, 월별 상호작용, 주민 행복 집계를 반영한다.
- **CITY:** 업무·교육·생산·창작·연구·주거·서비스 건물10개, 각 최대2단계 개선. 국가 조건 충족 시 착공하고 생산성·안정에 따라 여러 달 공사한다. 완공 교육 시설은 학습, 자동화 시설은 생산, 교통은 생활비, 녹지는 회복에 영향을 준다.
- **HUMAN:** 네 기질·욕구·우선순위·반복 행동 감점을 사용하는 Utility AI. 8개 직업군의 자동화 노출과 직무/AI 숙련, 소득·생활비·자산·복지·관계를 계산한다.

정상 속도는 하루/현실1초, 2×·4× 제공. 한 달·1년·5년·다음 중요 사건은 동일한 일별 코어를 순회하며 월 경계의 집계를 한 번씩 실행한다. 중요한 사건에 도달하면 남은 건너뛰기를 중단한다. 별도의 근사 경제식으로 갈아타지 않는다.

장기 진행 후 최대25개의 실제 월별 도시 스냅샷을 재생한다. 시각 재생은 세계/난수/저장을 수정하지 않는다. 과거 도시 화면에 현재 인물 상태가 섞이지 않도록 재생 중 주민·인물 카드를 숨기고 해당 프레임 날짜와 지표만 표시한다.

## 저장과 결산

별도 IndexedDB DB `inheritance-future-v2`, 슬롯 `saves/current`, 형식23. 명령/진행 후 자동 저장하며 파일 내보내기·불러오기를 지원한다. 잘못된 형식은 현재 상태를 교체하기 전에 거부한다. 미게시 형식20은 인구·정책·출생일·RNG를 보존하고 기존 `world`를 `nation.metrics`로 옮긴다. 과거 도시 증거는 만들지 않으며 이관 이후부터 공사를 계산한다. 선사시대 형식5는 그대로 별도 보존한다.

엔딩 우선순위: 불안정 전환 → 불평등 자동화 → 인간 중심 → 기술 번영 → 안정 중심. 지표 임계치로 판정하며 분배·환경·자유의 부차 결과, 가장 큰 변화, 비용과 개인 기록을 함께 표시한다. 단일 점수의 승패가 아니다.

## 알려진 한계·다음 우선순위

- 아트는 절차적으로 제작한 임시 쿼터뷰 픽셀 표현이다. 건물·공사·차량·보행·시설 개선은 실제 상태에 연결했지만 상용 고밀도 픽셀아트 완성본은 아니다.
- 180명 고정 초기 인구이며 출생·이민·여러 국가·2050년 이후는 아직 지원하지 않는다. 사망한 인물은 유지한다.
- 가족 지원과 관계 점수는 축약 모형이며 상세 관계망·가계 공동 의사결정은 미구현이다.
- 국가 정책과 10개 시설의 경제는 게임용 균형 모형이며 실제 예측이 아니다. 도시 건설은 정책 결과를 관찰하는 계층으로, 플레이어가 직접 건물을 배치하지 않는다.
- 전체 경로 자동 검사는 완료 조건·오류를 검증한다. 목표 20–35분의 재미와 밸런스, 실제 기기 성능을 사람의 체험으로 검증한 것은 아니다.
- 다음 우선순위: 실제 휴대폰/Safari 플레이 → 읽기 부담·생활 이벤트 빈도 조정 → 최종 아트 제작. 신규 시대·국가 확장은 별도 기획 확인 후 진행한다.
