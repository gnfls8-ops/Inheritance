# v2.0~v2.3 통합 개편 계획

기준: MASTER_SPEC.md. 0.8.0은 backup/pre-v2-0.8.0 태그로 보존. feature/future-v2 작업 브랜치 사용.

재사용: Mulberry32 단일 시드 RNG, GameClock, 아이소메트릭 좌표/이동 보간 설계, 네 기질과 Utility AI 원칙, React/Vite/PixiJS/Vitest. 기존 선사시대 모듈은 과거 소스로 보존하되 새 엔트리에서 불러오지 않음.

교체: 채집/부족/기술 발견 UI, 직접 인물 선택, 사망 후에만 계승, 선사시대 렌더링. 새 src/future 도메인으로 명확히 분리.

순서: 모델/정책/가상 인구 → 일별 행동·월 경제·세계 인과관계 → 조건 사건·관점 전환·결산 → IndexedDB 새 슬롯 → 현대 도시·반응형 UI → T01~T20와 실제 브라우저 전체 경로 → Pages 배포.

해석: 첫 정책 뒤 최초 추첨, 2034/2042 및 사망 때 재추첨. 중간 정책마다 재추첨하지 않음. 현재 인물은 정책의 지속 효과를 체험. 같은 삶에서 자유로운 교체 금지. 가상 분포의 현재 10세 이상 생존자 중 균등 추첨하며 정책 수혜/피해를 기준으로 고르지 않음.

집계: 장기 진행은 일별 핵심 계산을 동일하게 순회하되 UI/경로 렌더 갱신을 생략. 월 경제와 세계 계산은 월 경계에서 한 번. 180명·24년 규모에서 성능과 결과 일치를 검증. 렌더링된 NPC는 최대 24명.

새 세이브 버전 23 (미게시 v20은 LAYERS_ADDENDUM.md의 이관 규칙 적용) / 별도 IndexedDB DB와 슬롯. 기존 localStorage 및 선사시대 파일은 변환·삭제하지 않음. 미래 수치는 실제 통계나 예측이 아닌 게임 가상 규칙.

임시 아트는 직접 작성한 현대 도시 벡터/픽셀 표현으로 시작하며 현실적 인체 비율·이동·조건 기반 착공/공사/완공를 구현. 최종 상용 고밀도 픽셀아트 완성으로 보고하지 않음.

사용자 추가 AGE_ADDENDUM.md(v2.1) 우선 적용: 분포 기반 기존 나이, 생애 단계, 미성년 교육·부양, 노년 은퇴, 출생일 기반 노화와 생존/사망 결산 구분.

추가 승인 v2.2/v2.3은 LAYERS_ADDENDUM.md를 우선 적용한다. `nation.metrics`로 기존 지표를 명확화하며 global/city 계층을 신설한다.
