# INHERITANCE v2.1 — 무작위 연령 및 생애 단계 시스템

사용자 추가 명세. v2.0과 함께 적용하며 충돌하는 성인 전용 추첨 해석보다 우선합니다.

- 배정할 때 나이·직업·소득·기질을 선택하지 않습니다. 현재 가상 인구 분포를 반영해 인물을 추첨합니다.
- 인구가 이미 생성되면 그 인물의 기존 출생일과 나이를 사용하며 나이를 다시 추첨하지 않습니다.
- 같은 시드·상태의 추첨은 재현 가능해야 하고 정책의 유불리로 연령을 조작하지 않습니다.
- 생애 단계: 0~12세 아동기 / 13~19세 청소년기 / 20~34세 청년기 / 35~59세 중장년기 / 60세 이상 노년기.
- MVP 플레이 대상은 10세 이상 생존자입니다. 아동·청소년의 행동은 연령에 맞게 제한합니다. 전 연령 플레이는 장기 목표입니다.
- 나이는 교육 기회, 경제활동 가능 여부, 건강·체력, 관계·가족·부양, 은퇴, 개인 사건과 생애 전망에 영향을 줍니다.
- 나이가 호기심·지능·AI 활용 능력·행복을 직접 결정하지 않습니다.
- 전환 시 현재 인구에서 다시 추첨합니다. 이전 인물은 계속 살아가고 기록을 유지합니다. 나이는 출생일과 세계 날짜로 계산합니다.
- 2050년 생존 인물에게 중간 결산, 사망 인물에게 생애 결산을 제공합니다.

검사: 연령 분포 추첨 / 동일 시드 / 연령별 행동 제한 / 시간에 따른 노화 / 전환 후 이전 인물 상태 유지 / 사망자 재배정 방지.
