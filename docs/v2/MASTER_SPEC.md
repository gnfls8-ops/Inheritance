# PART 0. Codex 최상위 작업 지침

이 문서는 기존 INHERITANCE v1.0을 대체하는 새로운 마스터 명세서다.

기존 게임의 선사시대 생존·채집 중심 플레이는 더 이상 메인 게임 구조가 아니다.

이번 작업은 기존 시스템의 단순 확장이 아니라 게임의 핵심 루프를 변경하는 전면 개편이다.

## 0.1 반드시 수행할 작업

1. 기존 GitHub 저장소의 코드와 구조를 분석한다.
2. 재사용 가능한 시스템과 폐기해야 할 시스템을 구분한다.
3. 기존의 시뮬레이션 코어, 시드 난수, 게임 시계, NPC 기질, 자율 행동, 렌더링 기반은 가능한 한 재사용한다.
4. 선사시대 관련 게임 데이터와 UI를 현대·미래 시스템으로 교체한다.
5. 세계 이벤트, 거시적 선택, 무작위 인간 배정, 개인 생애, 사회 변화, 역사 분기를 연결한다.
6. 2026년부터 2050년까지 진행 가능한 완결된 첫 플레이 시나리오를 구현한다.
7. 시작 화면, 튜토리얼, 본편, 결산, 재시작까지 구현한다.
8. 테스트와 프로덕션 빌드를 통과시킨다.
9. GitHub Pages에서 정상적으로 실행되는지 검증한다.
10. 변경 사항과 남은 제한사항을 보고한다.

## 0.2 작업 운영 원칙

- 기존 저장소를 삭제하거나 새 저장소로 대체하지 않는다.
- 기존 프로젝트를 백업할 수 있도록 개편 전 Git 태그 또는 별도 브랜치를 남긴다.
- 기본 브랜치에 직접 대규모 변경을 적용하기보다 작업 브랜치에서 구현한다.
- 기존 사용자 세이브와 호환되지 않으면 세이브 버전을 변경하고 명확히 안내한다.
- 불필요한 라이브러리 교체를 피한다.
- 단계별로 테스트 가능한 상태를 유지한다.
- UI만 동작하는 가짜 프로토타입을 완성으로 보고하지 않는다.
- 이벤트 결과는 실제 세계 상태에 적용되어야 한다.
- 모든 선택지가 서로 다른 장기 결과를 만들어야 한다.
- 플레이어가 정상적인 게임 진행만으로 엔딩에 도달할 수 있어야 한다.

## 0.3 이번 작업의 완료 정의

다음 경험이 모두 가능해야 한다.

게임 시작 → 2026년 세계 상황 확인 → 중요한 미래 정책 선택 → 무작위 인간 배정 → 개인의 삶 플레이 → 사회 변화 경험 → 다음 역사 이벤트 → 인물 교체 및 생애 결산 → 2050년 도달 → 세계선 결산 → 재시작.

# PART 1. 게임의 정체성

## 1.1 핵심 콘셉트

> 당신이 선택한 미래를, 당신이 아닌 누군가로 살아가라.

INHERITANCE는 2026년부터 시작하는 미래 인류 시뮬레이션 게임이다.

플레이어는 세계의 중요한 역사적 분기점에서 선택을 내린다.

그 선택은 기술, 경제, 노동, 자유, 불평등, 사회제도, 인간의 생활방식에 영향을 미친다.

그러나 플레이어는 자신이 만든 세계에서 어떤 인간으로 살아갈지 선택할 수 없다.

세계 인구 중 한 인간이 무작위로 배정된다.

플레이어는 그 인간의 삶을 경험하면서 자신이 내린 거시적 결정이 개인에게 어떤 결과를 가져왔는지 확인한다.

이 과정이 반복되면서 인류는 서로 다른 미래로 발전한다.

## 1.2 게임의 철학

게임의 중심 주제는 인간의 본성, 기술 발전, 사회적 선택, 개인의 삶이다.

인간은 안정을 추구하면서도 새로운 것을 탐구한다.

기술은 인간에게 새로운 가능성을 제공하지만 기존의 질서와 생계를 위협할 수도 있다.

기술의 발전과 인간의 행복은 반드시 일치하지 않는다.

사회 전체에 이익이 되는 결정이 특정 개인에게는 불행을 가져올 수 있다.

반대로 사회 전체의 경제적 발전이 느리더라도 개인이 안정적이고 의미 있는 삶을 살아갈 수도 있다.

게임은 특정한 정치·경제적 결론을 정답으로 제시하지 않는다.

플레이어는 서로 다른 가치 사이에서 선택하고 그 결과를 경험한다.

## 1.3 핵심 디자인 원칙

1. 플레이어는 세계의 방향을 선택할 수 있다.
2. 플레이어는 자신의 출생 조건과 사회적 위치를 선택할 수 없다.
3. 세계의 변화는 실제 개인의 삶에 영향을 주어야 한다.
4. 개인은 세계의 변화에 수동적으로 반응하기만 하지 않고 자신의 삶을 선택할 수 있어야 한다.
5. 개인의 선택이 세계 전체를 쉽게 뒤집어서는 안 된다.
6. 거시적 결정에는 이익과 비용, 예상하지 못한 결과가 존재한다.
7. 인간의 기질은 행동에 영향을 주지만 운명을 결정하지 않는다.
8. 기술 발전은 반드시 행복이나 자유를 증가시키지 않는다.
9. 모든 세계선은 인과관계를 가진다.
10. 플레이어가 어떤 사회를 만들었는지 최종적으로 확인할 수 있어야 한다.

# PART 2. 핵심 게임 구조

## 2.1 이중 플레이 구조

게임은 두 개의 플레이 계층으로 구성한다.

### MACRO — 세계의 결정

플레이어는 역사적으로 중요한 사건에서 세계의 방향을 결정한다.

주요 선택 영역:

- AI 개발과 규제
- 노동 자동화
- 자동화 이익의 분배
- 교육 및 재교육
- 기업과 공공기관의 기술 접근성
- 에너지와 환경
- 인간과 AI의 관계
- 인간의 자유와 안전
- 사회보장 제도
- 생명공학과 인간의 변화

거시적 결정은 국가를 직접 통치하는 행위로 표현하지 않는다.

플레이어는 시뮬레이션 외부의 역사적 결정권자다.

이는 게임적 추상화이며, 선택의 효과는 현실적인 사회적 제약과 확률을 반영해 계산한다.

### MICRO — 인간의 삶

거시적 결정을 내린 이후 플레이어는 세계 인구에서 무작위로 배정된 인간 한 명을 플레이한다.

이 인물은 자신의 직업, 경제 상황, 기질, 관계, 지식, 건강, 생활환경을 가지고 있다.

플레이어는 다음 활동에 개입할 수 있다.

- 노동
- 학습
- AI 활용
- 창작
- 휴식
- 사회적 관계
- 공동체 활동
- 새로운 기회 탐색
- 생활방식 선택

인물은 기본적으로 자율 행동한다.

플레이어는 특정 행동을 지시하거나 우선순위를 변경할 수 있다.

## 2.2 핵심 플레이 루프

1. 현재 세계 상황 확인
2. 주요 역사적 사건 발생
3. 플레이어의 거시적 선택
4. 세계 상태 변화
5. 무작위 인간 배정
6. 개인의 생활과 자율 행동
7. 플레이어의 미시적 개입
8. 개인 이벤트와 사회 변화 발생
9. 개인 및 세계 상태 변화 확인
10. 다음 역사적 사건 또는 생애 종료
11. 인물 교체와 역사 기록
12. 새로운 세계선 진행

## 2.3 플레이어의 핵심 감정

게임이 만들어야 할 주요 감정은 다음과 같다.

- 호기심: 다음 시대에는 어떤 일이 발생할까?
- 책임감: 내 결정이 누군가에게 어떤 영향을 줄까?
- 놀라움: 예상하지 못한 사회적 결과가 발생했다.
- 공감: 내가 선택한 정책의 피해자가 되어 살아간다.
- 성취감: 개인의 노력으로 삶을 개선했다.
- 성찰: 내가 만든 세계는 정말 좋은 세계였을까?

# PART 3. 시간 시스템

## 3.1 시간 구조

시간은 생활 시간과 역사 시간으로 구분한다.

### 생활 시간

개인의 행동, 관계, 노동, 학습, 창작 등을 진행한다.

기본 단위는 1일이다.

### 역사 시간

반복적인 생활 과정을 요약하고 장기간의 변화를 계산한다.

1개월, 1년, 5년 단위의 시간 진행을 지원한다.

## 3.2 시간 조작

- 일시정지
- 1배속
- 2배속
- 4배속
- 1개월 진행
- 1년 진행
- 다음 중요 사건까지 진행

중요 이벤트 발생 시 자동 일시정지한다.

시간 건너뛰기 중에도 NPC의 생존, 소득, 관계, 기술 수용, 사회 변화는 계산되어야 한다.

단순히 날짜만 변경해서는 안 된다.

## 3.3 이벤트 중단 조건

시간 건너뛰기는 다음 상황에서 자동으로 중단한다.

- 주요 세계 이벤트
- 선택 인물의 중대한 개인 사건
- 사망
- 강제적인 인물 교체
- 파산 또는 생존 위기
- 플레이어의 직접 판단이 필요한 사건
- 엔딩 조건 충족

## 3.4 구현 방식

일 단위 시뮬레이션과 장기 집계 시뮬레이션을 구분한다.

장기 시간 진행 시 모든 캐릭터를 화면에서 하루씩 이동시킬 필요는 없다.

동일한 시드, 초기 상태, 입력, 진행 기간에서는 재현 가능한 결과를 생성한다.

장기 집계 방식과 일 단위 방식의 차이는 테스트를 통해 허용 범위 내로 관리한다.

# PART 4. 세계 시뮬레이션

## 4.1 세계의 주요 상태

MVP에서는 다음 지표를 0~100 범위로 관리한다.

| 지표 | 의미 |
|---|---|
| AI Capability | AI 기술 수준 |
| Automation | 노동 자동화 수준 |
| Productivity | 사회 생산성 |
| Employment | 고용 기회 |
| Wealth Equality | 경제적 분배의 균형 |
| Social Stability | 사회 안정성 |
| Freedom | 개인의 자유 |
| Public Welfare | 사회보장 수준 |
| AI Accessibility | AI 기술 접근성 |
| Public Trust | 기술과 제도에 대한 신뢰 |
| Environment | 환경 지속가능성 |
| Human Wellbeing | 사회 전체 삶의 질 |

모든 지표는 독립적으로 존재하지만 서로 영향을 준다.

예를 들어 자동화가 증가하면 생산성이 증가할 수 있다.

그러나 재교육과 사회보장 수준이 낮다면 고용 안정성과 삶의 질이 악화될 수 있다.

## 4.2 지표 변화의 원칙

정책은 단일 지표만 변경하지 않는다.

하나의 정책은 여러 지표에 긍정적·부정적 영향을 미친다.

정책의 효과는 현재 세계 상태에 따라 달라진다.

예를 들어 공공 AI 인프라 투자는 접근성을 높일 수 있지만 재정 부담과 운영 비용을 발생시킬 수 있다.

규제 완화는 혁신을 촉진할 수 있지만 신뢰나 안정성을 약화시킬 수 있다.

이러한 관계는 확정적인 현실 예측이 아니라 게임의 가상 시뮬레이션 규칙임을 명확히 한다.

## 4.3 MVP 세계 상태 초기값

2026년 시작 상태:

- AI Capability: 30
- Automation: 18
- Productivity: 45
- Employment: 72
- Wealth Equality: 42
- Social Stability: 65
- Freedom: 70
- Public Welfare: 48
- AI Accessibility: 35
- Public Trust: 50
- Environment: 55
- Human Wellbeing: 58

위 값은 게임 밸런스를 위한 가상 수치이며 실제 2026년의 통계가 아니다.

## 4.4 세계 상태 계산

초기 구현에서는 복잡한 경제 모델 대신 명시적인 인과관계 규칙을 사용한다.

예시:

AI 역량 증가 → 자동화 잠재력 증가

자동화 증가 + 재교육 부족 → 고용 기회 감소

자동화 증가 + 복지 및 분배 정책 → 삶의 질 개선 가능

기술 접근성 증가 → 학습 및 창작 기회 증가

불평등 심화 + 신뢰 감소 → 사회 안정성 악화

사회 안정성 악화 → 투자 및 기술 확산 속도 감소 가능

## 4.5 수치 계산 규칙

모든 지표는 0~100으로 제한한다.

정책 효과는 즉시 효과와 지연 효과로 나눈다.

권장 처리 순서:

1. 정책 선택 효과 등록
2. 즉시 효과 적용
3. 지연 효과 스케줄 등록
4. 매월 세계 상태 갱신
5. 지표 간 상호작용 계산
6. 임계값 기반 사건 검사
7. 연대기 기록

동일 효과가 중복 적용되지 않도록 정책 ID와 적용 이력을 관리한다.

## 4.6 장기 발전의 불확실성

AI 발전이 반드시 AGI로 이어지는 것은 아니다.

AGI 등장 시점은 고정하지 않는다.

특정 기술 수준과 연구 조건, 사회적 투자, 확률적 사건에 따라 발전 속도가 달라진다.

MVP에서는 AGI를 완전하게 구현하지 않고 장기 기술 발전의 잠재적 분기점으로 취급한다.

# PART 5. 무작위 인간 배정 시스템

## 5.1 핵심 원칙

플레이어는 자신이 살아갈 인간을 직접 선택할 수 없다.

세계 인구 분포를 바탕으로 인간 한 명이 무작위로 배정된다.

이 시스템은 INHERITANCE의 핵심 차별화 요소이므로 임의로 제거하거나 선택형 캐릭터 시스템으로 변경하지 않는다.

## 5.2 인간의 기본 데이터

- ID
- 이름
- 나이
- 성별 또는 캐릭터 표현 정보
- 지역
- 직업
- 소득
- 자산
- 교육 수준
- 기술 숙련도
- AI 활용 능력
- 건강
- 스트레스
- 행복
- 가족 및 관계
- 기질
- 현재 생활 상태
- 생애 기록

## 5.3 초기 직업군

MVP에서는 다음 직업군을 구현한다.

1. 사무직
2. 개발자·기술직
3. 제조·현장직
4. 서비스직
5. 교육·연구직
6. 예술·창작직
7. 자영업
8. 구직자·무직

직업별로 AI 자동화의 영향과 새로운 기회가 다르게 적용된다.

직업군별 영향은 고정된 운명이 아니라 기술 수준, 교육, 제도, 개인 능력에 따라 달라진다.

## 5.4 인구 분포

MVP에서는 100~300명의 가상 인구를 데이터로 유지한다.

실제 화면에 표시되는 NPC는 이 중 일부만 사용한다.

인구 분포는 직업, 소득, 연령, 교육 수준을 기준으로 생성한다.

초기 구현에서는 실제 인구 통계가 아닌 명시적으로 정의한 가상 분포를 사용한다.

무작위 배정은 해당 인구 분포를 반영한다.

## 5.5 추첨 규칙

- 정책 선택 이후 인간을 배정한다.
- 배정 결과는 정책의 유불리에 따라 조작하지 않는다.
- 추첨은 시드 기반 난수로 결정한다.
- 배정된 인간은 변경할 수 없다.
- 동일 시드와 동일한 세계 상태에서는 동일한 배정 결과가 재현된다.
- 극단적인 짧은 플레이를 방지하기 위해 최소 플레이 가능 기간을 보장하는 제한을 둘 수 있다.

## 5.6 개인 생애 종료

다음 조건에서 인물 교체가 발생할 수 있다.

- 사망
- 중대한 생애 종료 이벤트
- 장기 역사 진행에 따른 세대 전환
- 시나리오의 필수 관점 전환

인물 교체 시 생애 결산을 보여준다.

다음 인간은 현재 세계 인구에서 다시 추첨한다.

# PART 6. 인간의 기질과 행동

## 6.1 기질 시스템

기존의 네 가지 기질을 유지한다.

- 호기심
- 안정 추구
- 사회성
- 위험 감수

각 기질은 0~100이다.

기질은 행동 선택의 가중치에 영향을 준다.

## 6.2 개인의 욕구

다음 욕구를 관리한다.

- 경제적 안정
- 건강
- 관계
- 휴식
- 성취
- 탐구
- 자유
- 삶의 만족

## 6.3 자율 행동

인간은 자신의 상태에 따라 행동을 선택한다.

예를 들어 경제적 안정이 낮으면 노동이나 구직의 우선순위가 증가한다.

호기심이 높고 생활이 안정적이면 학습이나 창작의 우선순위가 증가할 수 있다.

스트레스가 높으면 휴식이나 관계 회복 행동의 우선순위가 증가한다.

## 6.4 플레이어 행동

MVP에서는 다음 행동을 구현한다.

### 노동

소득 증가, 시간과 체력 소모, 직업 숙련도 변화.

### 학습

지식과 기술 숙련도 증가, 시간과 비용 소모.

### AI 활용

생산성과 학습 효율 향상 가능, AI 접근성과 개인 숙련도에 영향받음.

### 창작

성취감 및 행복 증가 가능, 일부 활동은 경제적 성과로 연결.

### 교류

관계와 사회적 지원 증가.

### 휴식

체력 회복과 스트레스 감소.

### 새로운 기회 탐색

이직, 창업, 직업 전환 등의 이벤트 발생 가능.

### 공동체 활동

지역의 신뢰와 사회적 관계에 영향을 줌.

## 6.5 행동 점수

MVP의 행동 선택은 Utility AI 방식으로 구현한다.

각 행동의 점수는 다음 요소를 조합한다.

- 기본 행동 선호도
- 현재 욕구
- 기질 가중치
- 경제적 상황
- 사회적 상황
- 세계 기술 수준
- 최근 행동 반복 패널티

행동 점수의 계산 과정은 디버그 패널에서 확인할 수 있어야 한다.

## 6.6 행동 반복 방지

같은 행동을 지나치게 반복하지 않도록 한다.

- 행동 반복 패널티
- 욕구 변화
- 생활 사건
- 직업별 행동 차이
- 행동별 성취 목표
- 시간 건너뛰기

단, 반복적인 일상을 선호하는 인간도 존재해야 하므로 반복 행동 자체를 금지하지 않는다.

# PART 7. 개인의 경제와 삶

## 7.1 개인 경제

개인에게 다음 상태를 부여한다.

- 월 소득
- 생활비
- 자산
- 고용 상태
- 직업 안정성
- AI 활용 숙련도

월 단위로 수입과 지출을 계산한다.

자산이 부족하면 생활 스트레스가 증가할 수 있다.

사회보장 수준이 높으면 실직으로 인한 충격이 감소할 수 있다.

## 7.2 직업 변화

AI 자동화는 직업군별로 서로 다른 영향을 준다.

자동화가 증가하면 일부 업무 수요가 감소할 수 있다.

반대로 새로운 기술과 산업이 등장하면 다른 직업 기회가 증가할 수 있다.

직업 변화는 세계 지표와 개인의 숙련도, 교육 수준을 함께 반영한다.

## 7.3 행복과 삶의 질

행복은 소득만으로 결정하지 않는다.

다음 요소를 반영한다.

- 경제적 안정
- 건강
- 관계
- 자율성
- 성취감
- 스트레스
- 사회적 안전망
- 개인의 기질과 생활방식의 일치

높은 소득을 얻더라도 스트레스가 심하면 행복이 낮을 수 있다.

소득이 높지 않아도 관계와 생활 만족도가 높으면 행복이 높을 수 있다.

## 7.4 삶의 방향

플레이어는 개인의 삶에서 다음 방향을 선택할 수 있다.

- 경제적 성공
- 지식과 탐구
- 창작과 자아실현
- 관계와 공동체
- 안정적인 생활

이는 강제적인 직업 클래스가 아니라 행동 우선순위 프리셋이다.

언제든 변경할 수 있다.

# PART 8. 역사 이벤트와 세계선

## 8.1 이벤트 구조

각 세계 이벤트는 다음 데이터를 가진다.

- ID
- 제목
- 설명
- 발생 가능 시기
- 발생 조건
- 선택지
- 즉시 효과
- 지연 효과
- 개인 영향
- 후속 사건
- 역사 기록 문구

## 8.2 이벤트의 발생

이벤트는 단순히 특정 연도가 되었다고 강제로 발생하지 않는다.

현재 세계 상태와 선행 사건, 정책 선택, 기술 수준을 검사한다.

단, 첫 플레이의 흐름을 보장하기 위해 2026년 튜토리얼 이벤트는 고정 발생시킨다.

## 8.3 주요 이벤트 콘텐츠

첫 플레이에는 다음 10개 이벤트를 구현한다.

### E01 — AI의 대중화

시작 시점: 2026년.

선택:

- 민간 중심 AI 개발 촉진
- 공공 AI 접근성 확대
- 안전성 검증 우선

### E02 — 노동 자동화의 확산

발생 조건: 자동화 수준 상승.

선택:

- 자동화 촉진
- 재교육 확대
- 노동 보호 강화

### E03 — AI 교육 혁명

발생 조건: AI 접근성 및 교육 기술 발전.

선택:

- 공공 교육 투자
- 민간 교육 경쟁 촉진
- 전통적 교육 체계 유지

### E04 — 창작의 대중화

발생 조건: AI 역량 상승.

선택:

- 창작 도구 접근성 확대
- 창작자 권리 보호 강화
- 기존 제도 유지

### E05 — 자동화 이익의 분배

발생 조건: 생산성과 자동화 증가.

선택:

- 시장 중심 분배
- 사회보장 확대
- 공공 기술 배당 실험

### E06 — 인간과 AI의 신뢰

발생 조건: AI 역량과 사회적 의존도 상승.

선택:

- 자율적 활용 확대
- 투명성·책임 규제 강화
- 고위험 분야 사용 제한

### E07 — 새로운 노동의 의미

발생 조건: 자동화와 복지 수준 상승.

선택:

- 노동 중심 경제 유지
- 노동시간 단축
- 노동 외 활동 지원

### E08 — 에너지와 기술

발생 조건: AI 발전에 따른 에너지 수요 증가.

선택:

- 에너지 인프라 투자
- 환경 규제 강화
- 기술 효율화 우선

### E09 — 인간 능력의 확장

발생 조건: 높은 AI 역량과 기술 접근성.

선택:

- 인간과 AI 협업 확대
- 인간의 독립적 역량 유지
- 고도 기술의 신중한 도입

### E10 — 미래 사회의 방향

발생 조건: 2045년 이후.

선택:

- 생산성 중심 사회
- 자유와 자아실현 중심 사회
- 안정과 공동체 중심 사회

## 8.4 이벤트 선택의 효과

모든 선택지는 최소 다음 세 가지 효과를 가져야 한다.

1. 세계 지표 변화
2. 개인에게 영향을 주는 규칙 변화
3. 향후 이벤트 조건 또는 결과 변화

선택 후 설명 문구만 변경하고 실제 시뮬레이션 상태가 변하지 않는 구현은 허용하지 않는다.

## 8.5 이벤트 결과의 지연

일부 정책 효과는 즉시 발생한다.

다른 효과는 수년 후 발생한다.

예를 들어 재교육 정책은 즉시 고용률을 높이지 않을 수 있다.

하지만 시간이 지나면서 직업 전환 성공률에 영향을 줄 수 있다.

## 8.6 IF 세계선

세계선은 현재 상태와 선택 이력으로 정의한다.

선택에 따라 기술 발전 속도, 경제적 불평등, 사회적 안정, 개인의 생활방식이 달라진다.

실제 미래는 확정되지 않았으므로 모든 미래 결과는 게임의 가상 시뮬레이션으로 표시한다.

# PART 10. 무작위 인물과 관점 전환

## 10.1 관점 전환의 목적

플레이어가 자신의 거시적 결정이 사회의 서로 다른 인간에게 미치는 영향을 경험하도록 한다.

## 10.2 전환 시점

MVP에서는 다음 방식으로 운영한다.

- 2026년 최초 인물 배정
- 2034년 두 번째 인물 배정
- 2042년 세 번째 인물 배정
- 2050년 최종 결산

단, 사망이나 주요 이벤트에 따라 추가 전환이 발생할 수 있다.

이 연도는 첫 플레이를 보장하기 위한 시나리오 기준점이며, 정식 게임에서는 유연한 시간 구조로 확장한다.

## 10.3 인물 배정 방식

인물은 현재 세계 인구에서 무작위로 추첨한다.

직업, 소득, 기질, 지역 등은 현재 세계 상태에 따라 결정된다.

세계 정책의 결과를 보여주기 위해 특정 인물을 강제로 배정하지 않는다.

## 10.4 관점 전환 화면

다음 정보를 보여준다.

- 이전 인물의 생애
- 주요 사건
- 경제적 변화
- 삶의 만족도 변화
- 세계와 개인 결과 비교

# PART 14. MVP 엔딩

## 14.1 엔딩은 단일 지표로 결정하지 않는다

세계 상태의 여러 요소를 종합한다.

## 14.2 초기 엔딩 유형

### 기술 번영 사회

높은 생산성과 기술 접근성을 확보한 사회.

### 불평등한 자동화 사회

높은 자동화와 생산성에도 불구하고 경제적 격차가 큰 사회.

### 안정 중심 사회

기술 발전은 상대적으로 느리지만 사회적 안정성이 높은 사회.

### 인간 중심 사회

자유, 복지, 관계, 자아실현을 중시하는 사회.

### 불안정한 전환 사회

기술 발전과 사회제도의 불균형으로 갈등이 심화된 사회.

## 14.3 엔딩 판정

우선순위가 명확한 규칙 기반 분류를 사용한다.

동시에 여러 조건을 만족하면 엔딩 우선순위와 보조 특성을 함께 표시한다.

예를 들어 기술 번영 사회이면서 불평등이 높은 경우에는 불평등 문제를 결산에 반드시 반영한다.

## 14.4 장기 엔딩

다음 엔딩은 장기 개발 목표로 유지한다.

- 해방의 시대
- 통제의 시대
- 재건의 시대
- 별의 시대
- 인간 이후의 시대
- 히든 엔딩: 인간이란 무엇인가?

MVP에서 이 미래를 전부 구현할 필요는 없다.

## 15.2 핵심 모듈

전체 게임 상태와 틱을 관리한다.

세계 지표와 장기 변화를 계산한다.

거시적 선택과 정책 효과를 관리한다.

인구 분포와 인간 생성을 관리한다.

개인의 상태와 생애를 계산한다.

### BehaviorSystem

NPC 자율 행동을 결정한다.

### EconomySystem

개인 소득, 생활비, 자산, 직업 변화를 관리한다.

세계 이벤트와 개인 이벤트를 관리한다.

2050년 결산과 엔딩을 판정한다.

### SaveSystem

세이브와 불러오기를 관리한다.

### Renderer

도시, 인간, 환경을 렌더링한다.

## 15.3 시뮬레이션과 UI 분리

React 컴포넌트는 세계 상태를 표시하고 플레이어 명령을 전달한다.

세계 지표와 개인의 행동 결과는 시뮬레이션 코어에서 계산한다.

UI에서 임의로 세계 상태를 직접 변경하지 않는다.

## 15.4 결정론

동일한 초기 시드와 입력 기록에서는 동일한 결과가 재현되어야 한다.

난수는 단일 시드 기반 생성기를 사용한다.

난수 생성기 상태를 저장한다.

## 15.5 데이터 기반 콘텐츠

세계 이벤트, 개인 이벤트, 정책 효과, 직업 데이터는 JSON 또는 TypeScript 데이터 모듈로 관리한다.

게임 규칙을 UI에 하드코딩하지 않는다.

# PART 22. 절대 유지할 핵심 요소

다음 요소는 향후 개발 과정에서도 프로젝트의 정체성으로 유지한다.

1. 세계의 큰 결정은 플레이어가 내린다.
2. 플레이어가 경험할 인간은 무작위로 배정된다.
3. 세계의 결정이 개인의 삶에 실질적인 영향을 준다.
4. 개인의 삶은 자율 행동과 플레이어 개입으로 진행된다.
5. 인간의 기질은 각자의 선택과 반응을 다르게 만든다.
6. 기술 발전과 인간의 행복은 별개의 문제다.
7. 세계의 발전은 단일한 정답으로 수렴하지 않는다.
8. 선택의 결과는 시간이 흐르면서 누적된다.
9. 플레이어는 여러 인간의 관점에서 자신이 만든 사회를 경험한다.
10. 엔딩은 인간이 어떤 미래를 만들어냈는지를 보여준다.

# PART 23. 최종 구현 요청

현재 GitHub 저장소의 INHERITANCE 프로젝트를 이 명세에 따라 v2.0으로 개편한다.

우선 2026~2050년의 완결된 플레이 가능한 Vertical Slice를 구현한다.

단순한 UI 목업이나 시뮬레이션 데모가 아니라 실제로 다음 경험이 가능해야 한다.

**세계 이벤트 선택 → 무작위 인간 배정 → 개인 생활 → 세계 변화 → 다음 이벤트 → 인물 전환 → 역사 결산.**

모든 이벤트 선택은 실제 시뮬레이션에 반영한다.

플레이어가 정상적인 조작으로 2050년까지 도달할 수 있도록 한다.

구현이 완료되면 자동 테스트, 프로덕션 빌드, 배포 검증을 수행한다.

GitHub Pages에 배포 가능한 상태로 완성한다.

작업이 길어지는 경우 기능 단위로 커밋하고, 미완성 기능을 완성된 것처럼 보고하지 않는다.

**최종 목표: 플레이어가 자신이 선택한 미래를 무작위 인간의 삶으로 경험하는 게임을 실제로 플레이할 수 있게 만드는 것.**
