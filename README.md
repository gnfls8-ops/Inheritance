# INHERITANCE — The Future We Inherit

**2.4.0 테스트 빌드** · 2026–2050년 가상 기술 산업 국가 **아르카디아**의 정책을 선택하고, 무작위로 배정된 한 인간의 삶에서 그 결과를 경험합니다.

플레이: https://gnfls8-ops.github.io/Inheritance/?v=2.4.0

## 실행

Node.js 22.12 이상:

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

빌드 산출물은 `dist/`입니다. 정적 HTTP 서버에서 실행하며 GitHub Pages 하위 경로를 지원합니다. 최초 온라인 방문 후 서비스 워커 설치가 완료되면 오프라인 재방문도 가능합니다.

## 빠른 플레이

1. 새 미래 시작 → 첫 국가 정책 세 가지 중 하나를 선택합니다.
2. 현재 인구에서 배정된 인물의 나이·직업·소득·기질을 확인합니다. 직접 고르거나 다시 추첨하지 않습니다.
3. `나의 삶`에서 생활 우선순위와 다음 하루의 행동을 정합니다. 지시가 없으면 자율 생활합니다.
4. `한 달`, `1년`, `5년`, `다음 중요 사건`으로 진행합니다. 중요 사건에서는 자동 정지합니다.
5. 월별 도시 기록은 타임랩스로 재생됩니다. 정지하거나 현재 시점으로 건너뛸 수 있습니다.
6. 2034·2042년과 현재 인물의 사망 후 다른 관점으로 이어집니다. 살아 있는 이전 인물은 계속 생활합니다.
7. 2050년에는 국가의 미래와 경험한 인물들의 중간/생애 결산을 확인합니다.

시민 클릭은 **관찰**입니다. 다른 사람에게 행동 명령을 내리거나 클릭으로 플레이 인물을 바꿀 수 없습니다. 20세 미만은 노동·구직 대신 교육·관계·창작·AI 활용·휴식·공동체 활동을 합니다. 60세 이상은 은퇴를 선택할 수 있습니다.

## 세계와 도시

`GLOBAL → NATION → CITY → HUMAN` 계층을 사용합니다. 독립적인 세계 기술 발전이 국가의 기술 확산과 환경에 영향을 주고, 정책은 국가의 12개 지표와 생활 규칙을 바꿉니다. 도시 사업은 실제 국가 조건을 충족할 때 착공하며 여러 달에 걸쳐 완공됩니다. 교육·교통·자동화·녹지 기반은 개인의 학습·가계·생산·회복에 연결됩니다.

생활 관찰은 인물을 크게 보여 주고 가장자리에서 부드럽게 추적합니다. 도시 관찰로 전체 생활권을 볼 수 있습니다. 카메라 드래그·휠·두 손가락 확대를 지원합니다. `내 인물 따라가기`로 추적하고 직접 지도를 움직이면 추적을 해제합니다. 모바일은 지도 위에서 여닫는 창을 사용합니다. 기본 하루6초(2×/4×)로 출근·학습·쇼핑·교류·귀가 동선을 관찰하세요. 머리 위 말풍선은 실제 상태와 사건을 반영하며, `정책 결과`에서 원인 정책과 실현된 파급을 추적할 수 있습니다.

## 저장과 호환

IndexedDB `inheritance-future-v2` / `saves/current`, 저장 형식24. 진행마다 자동 저장하며 설정에서 JSON을 내보내거나 가져올 수 있습니다. v20/v23 미래 저장은 인물·정책·난수 상태를 유지해 이관합니다. 이전 도시 공사 기록은 만들어내지 않고 이관 시점부터 시작합니다. 선사시대 localStorage 저장과 백업은 삭제하지 않습니다.

기존 0.8.0은 `backup/pre-v2-0.8.0` 태그와 이전 소스로 보존했습니다. 새 엔트리는 `src/future`만 사용합니다. 이전 선사시대 문서는 과거 버전에 대한 기록입니다.

## 검증과 범위

[v2.4 구현·검증 보고서](docs/v2/V24_RELEASE.md), [통합 계획](docs/v2/PLAN.md), [연령 추가 명세](docs/v2/AGE_ADDENDUM.md), [세계·도시 계층](docs/v2/LAYERS_ADDENDUM.md).

`python scripts/check_human_focus.py`는 로컬 프로덕션 서버에서 Chromium 전체 플레이·저장·모바일 뷰포트·오프라인 검사를 수행합니다. `python scripts/check_v24_scenario.py`는 명시적으로 구성한 2030 사무직 테스트 조건에서 설비→실직→재교육→수년 후 결과를 검증합니다. 이 테스트 조건은 정상 무작위 배정 플레이와 구분합니다. Playwright 및 Chromium이 필요합니다. `INHERITANCE_URL`로 서버 주소를 지정할 수 있습니다.

현재 수치는 가상 게임 규칙이며 실제 미래 예측이 아닙니다. 아트는 직접 제작한 쿼터뷰 픽셀 표현의 임시 자산입니다. 상용 수준 고밀도 아트, 실제 휴대폰/Safari, 2050년 이후·여러 국가 확장은 별도 검증/개발 범위입니다. 비공개 기록실·스크린샷·저장 데이터는 `release/`, `dev-dashboard/private/`, `dev-dashboard/site/data/`에만 보존하며 게임 사이트에 포함하지 않습니다.
