# INHERITANCE

한 시점에 한 인간의 삶만 조작하는 역사 시뮬레이션. 현재 빌드는 **PLAYTEST 0.6.0**이며 선사시대 골짜기에서 생존·관계·기술 전승·사망·계승을 플레이할 수 있습니다. 최신 기준은 [플레이 테스트 수정 명세](docs/PLAYTEST_REVISION.md)입니다.

## 실행
Node.js 22.12 이상에서:
```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```
빌드 결과는 `dist/`입니다. 정적 HTTP 서버에서 제공합니다.

## 조작과 시간
첫 인간을 선택하고 재생합니다. 다른 인간 선택은 관찰이며 직접 명령할 수 없습니다. 하단 메뉴는 인물·행동, 시간, 연대기, 설정 창을 열고 닫습니다. 모바일은 지도 위에 창을 겹쳐 표시하며 창 내부만 스크롤합니다.

내 인물에게 이동·채집·탐험·휴식·교류·실험·전파를 지시합니다. 행동은 한 번 완료 후 자율 행동으로 돌아갑니다. 식량 부탁은 3칸 이내, 같은 상대에게 7일 간격이며 거절될 수 있습니다. 교류는 같은 상대와 4일 간격입니다. 지도 드래그·휠·핀치 및 인물 추적을 지원합니다.

1배속에서 생활은 현실 1초당 1일, 생애는 30일, 역사는 1,825일입니다. 생활·생애는 같은 일별 상세 계산을 사용합니다. 역사는 이동·접촉을 집계하고 자원·욕구를 근사 계산하므로 상세 모드와 결과가 동일하지는 않습니다. 모든 모드에서 같은 출생·노화·사망 함수를 사용합니다. 출생은 성인 2명 이상·인구 30명 미만·자원 조건하에 30일마다 확률 판정합니다. 건강 0 또는 80세 노령에 사망합니다.

생존 중 은퇴·계승은 불가능합니다. 사망 → 생애 결산 → 역사 관찰 또는 새 인물 선택 순서입니다. 중요 사건·사망에서 시간 묶음을 즉시 중단하며 새 삶은 생활 모드·일시정지로 시작합니다. 백그라운드 탭은 자동 정지합니다.

## 기록과 저장
직접 발견, 배움, 전승, 주요 교류, 사망은 개인 연대기에 남습니다. 전승은 송신·수신 인물의 ID와 이름, 날짜, 방법을 보존합니다. 상세 사망 인물이 정리되어도 연대기 이름은 유지됩니다. 일반 행동 로그는 최근 100건, 세계 사건은 200건을 보존합니다.

설정에서 JSON 저장·불러오기를 제공합니다. 저장 형식은 v3이며 v1/v2를 마이그레이션합니다. 이전 v2에서 은퇴한 원래 인물이 살아 있으면 세계를 유지하고 그 인물로 복귀합니다. 불러오기는 일시정지로 시작합니다. 자동 저장은 2초마다 이 브라우저에 보관하며 다음 방문에 일시정지로 복원합니다. 직전 저장을 백업하고, 손상된 최신 저장은 백업으로 복구합니다. 장기 진행의 대기 명령은 손실 없이 압축합니다. 저장 공간이 부족하거나 접근이 차단되면 설정에 파일 저장 안내를 표시합니다. 화면의 제1일은 내부 경과 일수 0입니다.

## 음향과 사건 안내
설정에서 자연·효과음을 켤 수 있습니다. 브라우저에서 합성한 바람·물소리와 짧은 행동/중요 사건 음을 사용합니다. 기본값은 꺼짐이며 일시정지하면 자연음도 잦아듭니다.

45게임일 이상 지났고 주변에 살아 있는 NPC가 있으면 비차단 대화 기회를 안내합니다. 안내를 눌러야 사건 창이 열립니다. 발생 기준은 시간 모드가 아닌 게임 내 경과 일수입니다. 생애 모드의 주요 만남과 역사 문화 사건은 기존 게임 일수 기반 확률을 유지합니다.

## 아트와 렌더링
`scripts/make_art.py`가 Pillow로 생성하는 프로젝트 전용 픽셀 스프라이트를 사용합니다. 외부 게임 이미지를 사용하지 않습니다. 재생성은 `python scripts/make_art.py`이며 실행 시에는 Python이 필요 없습니다.

나무·바위·강·초목·거처와 인물의 보행·작업·휴식 동작, 물결·계절 색상·카메라 보간을 제공합니다. 불·석기·저장물은 지식 보유자를 기준으로 표시하며 공동체 화덕은 기술 정착 후 표시합니다. 거처는 배경 소품이며 건설 시스템이 아닙니다. 렌더링 보간은 게임 상태와 난수에 영향을 주지 않습니다.

## 검증과 남은 범위
`npm test`는 단일 인물 권한, 사망·사건 중단, 동일 입력 재현성, 300년 역사 진행, 저장 호환성, 전승 기록, 쿨다운과 이동 보간을 검증합니다. 브라우저 검증 기록은 [검증 보고서](docs/PLAYTEST_VALIDATION.md)를 참고하세요.

현재 아트는 선사시대 지역용입니다. 이후 시대의 건축·의복·도시 변화는 사용자 결정에 따라 별도 설계로 남겼습니다. 실제 모바일 기기 성능 검증과 Safari 검증은 환경 제약으로 미완료입니다. 역사 모드는 집계 근사이며 실제 인류 역사나 인구를 재현하는 모델이 아닙니다.
