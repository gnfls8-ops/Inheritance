# INHERITANCE

한 인간의 삶을 통해 역사를 경험하는 오프라인 싱글플레이 시뮬레이션.
현재 **STEP 4 — 기술과 지식**까지 구현했습니다. [마스터 명세](docs/MASTER_SPEC.md)를 기준으로 하며 STEP 5 이후는 구현하지 않았습니다.

## 실행

Node.js 22.12 이상(검증: 24.19.0), npm 11 사용.

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

## 조작

- 지도에서 인물을 클릭/터치하거나 우측 목록에서 선택합니다.
- 땅을 누르면 선택한 인물의 이동 경로를 예약합니다. 강과 암석은 통과할 수 없습니다. 도달 불가능한 목적지는 안내 메시지를 표시합니다.
- 모든 인물은 욕구·기질·자원·주변 인간에 따라 자율 행동합니다.
- 우측 인물 패널에서 채집·탐험·휴식·교류를 지시하거나 `지시 취소 · 자율 복귀`를 누를 수 있습니다. 행동은 한 번 완료 후 자율 행동으로 복귀합니다.
- 재생하면 하루에 한 칸씩 이동합니다. 일시정지 중 예약 가능하며, 새 이동 명령은 기존 경로를 교체합니다.
- 마우스/터치 드래그로 카메라 이동, 휠/두 손가락 핀치로 줌(0.22~2.5배).
- `선택 인물 / 중앙으로`는 선택 인물(미선택 시 지역 중앙)로 카메라를 돌려놓습니다.
- `인물 추적`을 켜면 매 틱 선택 인물을 화면 중앙에 유지합니다.
- 시드를 바꾸고 `다시 시작`을 누르면 일시정지 상태의 새 세계로 초기화됩니다.

## 구조와 의존성

- `src/simulation/`: 순수 TypeScript 데이터 모델, Mulberry32 난수, `Simulation.step()`, 고정 틱 시계, 지형 생성·좌표 변환·BFS 경로 탐색. React·Pixi·브라우저 API에 의존하지 않습니다.
- `src/ui/`: React UI, 브라우저 프레임 스케줄링, 렌더러 생명주기. 재생/정지, 1·2·4배속, 시드 재시작, 인물 정보·선택.
- `src/rendering/`: PixiJS WebGL 렌더러, 카메라와 입력 처리. 정적 타일은 텍스처 캐시, 나무·암석·인물은 지면 Y 기준 깊이 정렬.
- React/React DOM은 UI, Vite는 개발·번들링, TypeScript는 타입 검사, PixiJS는 2D 렌더링, Vitest는 자동 테스트를 담당합니다. STEP 2·3에서 추가한 의존성은 없습니다.

## 시뮬레이션 규칙

- 초기 상태는 일시정지. 1배속에서 실제 1초 = 1게임일(1틱). 화면의 제1일은 내부 tick 0입니다.
- 렌더링 프레임 간격과 독립적으로 정수 틱을 진행합니다. 일시정지할 때 부분 틱은 버립니다. 배속 변경은 이미 누적된 게임 시간을 보존합니다.
- 탭이 백그라운드로 가면 자동 일시정지하며 복귀 시 사용자가 재생합니다.
- 시드는 unsigned 32-bit 정수(0 포함). 동일 시드·명령 순서·틱 수로 동일 스냅샷을 재현합니다.
- 48×48 지형은 숲·초원·강·암석으로 생성하며, 12명은 걸을 수 있는 중앙 공터에서 시작합니다.
- 타일은 64×32 논리 픽셀, 정사영 아이소메트릭 좌표입니다. BFS는 상·우·하·좌 고정 순서로 네 방향 최단 경로를 찾습니다.
- 각 일일 진행과 유효 이동 명령은 현재 tick과 함께 기록합니다. 이동 명령은 난수를 소비하지 않습니다.
- 이동 명령의 목적지에 도착한 다음 틱부터 자율 행동을 다시 선택합니다.
- 다른 인물과 같은 타일을 지나갈 수 있습니다. 군중 충돌이나 대각선 이동은 구현하지 않았습니다.
- 스냅샷에는 버전·난수 상태·지형·인물·경로·명령이 포함됩니다. IndexedDB 저장·불러오기는 STEP 7 범위입니다.

## 검증

`npm test`는 시드 재현성, 시계·배속·정지, 스냅샷 격리, 48×48 지형 재현, 전체 타일 좌표 변환, 장애물 우회·도달 불가 처리, 이동 명령 재현을 검사합니다.
`npm run build`는 TypeScript 타입 검사 후 프로덕션 번들을 생성합니다.

현재 클라우드의 Chromium 소프트웨어 WebGL에서도 지도 표시·입력·NPC 행동 및 플레이어 지시 UI를 검증했습니다. 실제 휴대폰 GPU 성능·브라우저별 호환성은 추가 확인이 필요합니다.

## 현재 제한 / 다음 단계

지형·인물은 교체 가능한 Pixi 벡터 임시 그래픽이며 최종 리얼리스틱 픽셀아트가 아닙니다. 캐릭터는 성인 신체 비율로 표시하지만 보행 애니메이션과 보간은 아직 없습니다. 이동은 고정 틱에서 타일 단위로 진행합니다.

기질·생존 욕구·자율 행동·개인 식량·자원 소진/재생·관계와 행동 기록을 구현했습니다. [STEP 3 규칙과 검증](docs/STEP3.md)을 참고하세요. 기술 발견·전파·수용·소실은 [STEP 4 규칙](docs/STEP4.md)에 따라 구현했습니다. 역사 사건·출생·노화·사망·세대 계승·저장은 이후 단계입니다. 건강이 0이 되어도 현재 단계에서는 사망하지 않습니다. 새로고침하면 게임 상태가 초기화됩니다.

STEP 5는 별도 진행 지시 후 구현합니다. 환경 게시나 Git 커밋·푸시는 수행하지 않았습니다.

## STEP 4 플레이

인물을 선택하고 우측 패널을 스크롤해 기술 영역을 엽니다. 식량 저장 실험을 예약하고 재생하세요. 발견 후 다른 인물 가까이 이동해 전파를 시도합니다. 실험 실패·전파 거부도 가능한 결과입니다.
